# AI-Powered College Helpdesk

An AI-powered college helpdesk designed to help students quickly
find answers to college-related questions.

## Problem Statement

Students often need to search through different college websites,
PDFs, notices, departments, and administrative offices to find
basic information.

The AI-Powered College Helpdesk provides a single intelligent
platform where students can ask questions in natural language
and receive relevant answers.

## Key Features

- AI-powered student chatbot
- College FAQs
- Academic information
- Examination information
- Fees and scholarship information
- Department information
- College notices
- Admin dashboard
- Document/knowledge management
- Chat history

## Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Python
- FastAPI

### Database
- PostgreSQL

### AI
- Large Language Model (LLM)
- Retrieval-Augmented Generation (RAG)
